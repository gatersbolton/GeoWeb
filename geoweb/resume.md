### 项目：GeoWeb 钻孔椭圆度 Web 应用（全栈工程化集成）
时间：2024.10 - 2025.10（校内科研项目）

概述：
- 将课题组既有的 Python 科学计算与可视化程序（钻孔椭圆度算法及绘图）工程化为可在线使用的 Web 应用，面向地球物理/地质领域科研与教学使用场景。
- 本人负责 Web 应用的整体架构与落地：前端交互、后端 API 网关与文件上传、与 Python 微服务的稳定对接、进度监控与可视化体验优化；算法代码非本人编写，来自课题组师兄。

技术栈：
- 前端：Vue 3、Vite、Element Plus、Axios
- 后端：Spring Boot 3（WebFlux）、MyBatis、MySQL、Maven
- 微服务：FastAPI、pandas、numpy、matplotlib，异步执行与进度轮询/WS

核心工作与难点突破：
- API 设计与微服务编排：抽象“计算/进度/结果/下载/可视化”接口，后端以 WebFlux 作为网关转发到 FastAPI；对长耗时任务采用“异步启动 + 进度轮询（或WS） + 结果获取”的交互协议，显著提升前端可用性与可靠性。
- 大文件上传与稳定性：提升后端上传与缓冲限制（至 500MB），细化错误分类（超限/CSV 解析/权限等）；前端增加超时与状态提示，避免卡死与误操作。
- 可视化体验优化：实现“滑条控制深度窗口 + 预览/最终质量双模渲染”，拖动时走 lightweight 预览，释放后请求高清版本，兼顾流畅与清晰度。
- 进度监控组件：封装 `ProgressMonitor`，以轮询快速落地（服务端亦支持 WS）；对非百分比阶段（Loading/Saving）做节流与智能日志输出，减少噪音。
- 工程化与可运行性：完成 README、启动顺序与本地代理配置；前端代理 `/api`、`/user` 到 8081，计算微服务跑在 8000，开发者可一键起服务。

结果与影响：
- 课题组成员无需本地安装复杂科学计算环境即可在线体验与批量试算，显著降低试用门槛；演示数据模式支持教学展示。
- 统一的下载接口导出标准 CSV；可视化参数与窗口选择更贴合科研使用习惯。

我在项目中的边界与说明：
- 我负责 Web 应用架构、后端转发、上传/进度/下载协议、前端交互与可视化工作流。算法与其可视化核心实现来自课题组既有 Python 仓库（非本人编写）。

可量化指标（样例）：
- 500MB 上传能力（后端与前端联动策略），超时默认 5 分钟可配置。
- 计算流程端到端时延：演示数据 10-30s；真实数据取决于 CSV 规模与机器性能。
- 可视化交互帧延：预览模式下滑动 200ms 节流，减少抖动与请求风暴。
