# 钻孔椭圆度项目进度监控系统

## 🎯 功能概述

这个系统为钻孔椭圆度计算项目添加了实时进度监控功能，用户可以在Web界面中看到计算的实时进度，包括百分比进度条和详细的处理日志。

## 🚀 新特性

### 1. 实时进度显示
- **进度条**：显示计算完成的百分比（0-100%）
- **状态指示**：正在运行/已完成/出错的视觉指示
- **实时日志**：显示处理过程中的详细信息

### 2. WebSocket通信
- 使用WebSocket实现服务端到客户端的实时消息推送
- 无需页面刷新即可获取最新进度
- 支持多个用户同时进行计算

### 3. 异步处理
- 计算在后台异步执行，不会阻塞用户界面
- 用户可以在计算过程中进行其他操作
- 支持计算重试功能

## 📱 用户界面

### 新增组件：进度监控器
- **位置**：在钻孔椭圆度页面的计算按钮下方
- **显示条件**：点击"开始计算"后自动显示
- **主要元素**：
  - 进度条（带百分比）
  - 当前状态文本
  - 处理日志窗口
  - 操作按钮（查看结果/重新计算/关闭）

## 🔧 技术实现

### 后端修改
1. **WebSocket支持**：
   - 新增 `/ws/progress/{session_id}` WebSocket端点
   - 实现连接管理和消息广播

2. **异步API**：
   - 新增 `/borehole/calculate_async` 异步计算端点
   - 新增 `/borehole/result/{session_id}` 结果获取端点

3. **进度回调**：
   - 修改核心处理函数支持进度回调
   - 在关键处理点发送进度更新

### 前端修改
1. **进度监控组件**（`ProgressMonitor.vue`）：
   - 进度条显示
   - 日志窗口
   - WebSocket连接管理
   - 事件处理

2. **页面集成**：
   - 修改钻孔椭圆度页面集成进度监控
   - 更新计算流程使用异步API
   - 添加状态管理

## 🎮 使用步骤

### 1. 启动服务
```bash
# 启动Python后端服务
cd python_service
python app.py

# 启动前端服务
cd frontend
npm run dev
```

### 2. 访问界面
- 打开浏览器访问：http://localhost:3000
- 导航到"钻孔椭圆度项目"页面

### 3. 执行计算
1. 选择使用演示数据或上传自己的文件
2. 设置计算参数
3. 点击"开始计算"按钮
4. 观察进度监控器中的实时进度
5. 计算完成后查看结果

## 📊 进度信息详解

### 进度阶段
1. **初始化**（0-10%）：加载数据文件
2. **数据处理**（10-95%）：椭圆拟合计算
3. **保存输出**（95-98%）：生成结果文件
4. **完成**（100%）：所有处理完毕

### 状态类型
- **info**：普通信息（蓝色）
- **success**：成功消息（绿色）
- **warning**：警告信息（橙色）
- **error**：错误消息（红色）

### 常见问题
1. **WebSocket连接失败**：
   - 检查防火墙设置
   - 确认后端服务正在运行
   - 检查端口8000是否被占用

2. **进度不更新**：
   - 检查浏览器控制台错误
   - 确认WebSocket连接状态
   - 重新刷新页面

3. **计算失败**：
   - 检查后端日志输出
   - 验证输入文件格式
   - 确认计算参数有效性

## 🛠️ 开发者信息

- **WebSocket端点**：`ws://localhost:8000/ws/progress/{session_id}`
- **异步计算API**：`POST /borehole/calculate_async`
- **结果获取API**：`GET /borehole/result/{session_id}`
- **进度消息格式**：
  ```json
  {
    "type": "progress|completed|error",
    "message": "处理消息",
    "percentage": 50.5,
    "timestamp": "2024-01-01T10:30:25.123Z"
  }
  ```
