## 概述

现在已经成功将现有的 `python/Borehole ellipticity` 项目集成到 FastAPI web 应用中。新的系统**直接调用现有的程序**，而不是重新实现算法。

- **复用现有算法**: 直接使用 `borehole_ellipticity.py` 中的科学算法

## API 接口详情

### POST `/borehole/process`

**输入参数:**
- `tt_file`: ATV 旅行时间数据文件 (CSV格式，必需)
- `wtt_file`: ATV 工具声窗旅行时间文件 (CSV格式，可选)
- `mask_file`: 掩码文件 (CSV格式，可选)
- `rp`: ATV 工具声学头半径 (米，必需)
- `vf`: 钻孔流体声速 (m/s，必需)
- `wtt`: 声窗旅行时间值 (如果没有WTT文件时使用，可选)
- `beta`: 时间单位转换系数 (可选)

**输出结果:**
```json
{
  "ellipticity_plot": "data:image/png;base64,...",
```
