# 钻孔椭圆度项目修改说明

## 修改概述

按照用户需求，将项目逻辑重新设计为分离的计算和显示两个部分，并增加了默认演示数据选项。

## 主要修改内容

### 1. 新建前端界面

**文件**: `frontend/borehole_ellipticity.html`

- 创建了专用的钻孔椭圆度计算与可视化界面
- 采用4步骤工作流程：
  1. 计算参数设置
  2. 椭圆度计算
  3. 显示参数设置  
  4. 结果可视化
- 增加了勾选框，支持使用默认演示数据
- 响应式设计，支持移动端和桌面端

### 2. 后端API分离

**文件**: `python_service/app.py`

#### 新增接口：

1. **`/borehole/calculate`** - 椭圆度计算接口
   - 支持文件上传和演示数据选项
   - 返回session_id用于后续可视化
   - 提供计算结果统计信息

2. **`/borehole/visualize`** - 可视化生成接口
   - 基于session_id获取计算结果
   - 支持可视化参数自定义
   - 生成增强版图表

3. **`/borehole/download/{session_id}/{filename}`** - 结果文件下载接口
   - 支持下载椭圆度参数、中心化旅行时间等结果文件

#### 主要特性：
- 使用session管理保持计算结果
- 支持演示数据模式
- 完善的错误处理和文件大小限制

### 3. 可视化模块增强

**文件**: `python/Borehole ellipticity/vis_wrapper.py`

#### 新增函数：

1. **`generate_enhanced_plots()`** - 增强图表生成
   - 更符合`dispEllip.py`的原始输出风格
   - 支持多列显示：振幅图像、半径图像、椭圆参数等
   - 动态调整列数和显示内容

2. **`generate_dispellip_style_plot()`** - dispEllip风格图表
   - 完全重现原始dispEllip.py的多列布局
   - 支持ATV振幅、半径、倾角、方位角等数据的综合显示
   - 保持原有的颜色映射和样式

### 4. 后端路由配置

**新增文件**:
- `backend/src/main/java/com/geoweb/demo/controller/StaticController.java`
- `backend/src/main/java/com/geoweb/demo/config/WebConfig.java`

配置Spring Boot以支持新的前端界面路由。

### 5. 项目结构优化

```
geoweb/
├── frontend/
│   ├── borehole_ellipticity.html    # 新的专用界面
│   └── geomap.html                  # 原地应力可视化界面
├── backend/                         # Spring Boot后端
├── python_service/                  # Python FastAPI服务
└── python/Borehole ellipticity/     # 椭圆度计算核心代码
```

## 新的工作流程

1. **用户访问** `http://localhost:8080/borehole`
2. **步骤1**: 设置计算参数，可选择使用演示数据
3. **步骤2**: 后端进行椭圆度计算，显示进度和结果统计
4. **步骤3**: 设置可视化参数（颜色映射、显示范围等）
5. **步骤4**: 生成并显示可视化结果，支持下载数据文件

## 主要改进

1. **用户体验**：
   - 清晰的4步骤流程指引
   - 实时进度显示和错误提示
   - 支持演示数据快速体验

2. **功能分离**：
   - 计算和显示完全分离
   - 支持重新设置参数而无需重新计算
   - 灵活的可视化配置

3. **可视化增强**：
   - 更符合原始dispEllip.py的输出
   - 支持多种数据源的综合显示
   - 动态列数调整

4. **系统架构**：
   - 前后端分离设计
   - RESTful API接口
   - Session管理机制

## 启动方式

1. 启动Python服务：
```bash
cd python_service
python app.py
```

2. 启动Spring Boot后端：
```bash
cd backend
mvn spring-boot:run
```

3. 访问界面：
   - 钻孔椭圆度系统：`http://localhost:8080/borehole`
   - 原地应力系统：`http://localhost:8080/geomap.html`

## 注意事项

1. 确保演示数据文件存在于 `python/Borehole ellipticity/data/` 目录
2. Python服务默认运行在8000端口
3. Spring Boot服务默认运行在8080端口
4. 支持的文件格式：CSV（最大500MB）

## 兼容性

- 保持了原有`borehole_ellipticity.py`的所有功能
- 新的可视化模块向后兼容
- 原有的地应力可视化系统不受影响
