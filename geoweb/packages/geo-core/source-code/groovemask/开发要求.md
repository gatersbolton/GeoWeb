b1. 你应该让 Codex 实现的“默认后处理算法”
算法名字

GrooveMask-Inpaint（推荐默认）

处理对象假设

输入是 井壁展开图，x 方向为方位，y 方向为深度。

伪影是 窄而长的近竖直条带，通常是暗带，也允许亮带。

条带可能贯穿全图，也可能只在一部分深度存在。

图像左右边界在物理上是相邻方位，所以 x 方向必须按圆周 wrap-around 处理。

该算法刻意不处理宽带、低频、平滑的方位阴影，避免误伤去中心化类伪影。

核心思路

把问题拆成两步：

第一步，只找“像 groove 的窄竖带”。
第二步，只在这些带状区域里修补，未掩膜区域尽量不改。

这比“整图去条纹”更适合 stabilizer groove。

2. 输入、输出和运行模式
输入

支持两类输入：

原始灰度/标量图（优先）
例如导出的 ATV 幅度矩阵或 16-bit TIFF。

彩色截图/PNG/JPG（也支持）
如果只有伪彩截图，就先转成工作灰度通道，再把修正量回写到 RGB。

输出

程序至少输出这些文件：

clean.png：去 groove 后的图

mask.png：检测到的 groove 掩膜

overlay.png：原图 + 掩膜叠加

diff.png：clean - raw 的差值图

tracks.json：每条 groove 的中心列、宽度、起止深度、置信度

debug/：中间结果，方便调参

模式

detect-only：只检测，不修补

clean：检测 + 修补

batch：对整个文件夹批量处理

3. 推荐默认流程
Step A：ROI 裁剪与边界处理

如果输入是截图，往往两边有尺子、边框、白边。先做 ROI 提取。

建议规则

支持 --roi x0 x1 y0 y1 手工指定。

同时实现 auto_crop：

按列统计非白像素比例、列方差、列熵；

取“内容最丰富且连续最长”的中心区作为 borehole image panel；

去掉两侧黑边框 1–3 像素。

必做：圆周扩展

因为展开图左右边是相邻方位，所有检测和修补前，都要做一层 circular padding：

左侧补右边若干列

右侧补左边若干列

处理完成后再裁回

这个步骤很关键，否则 0°/360° 附近的 groove 会被误分成两条。

Step B：构造工作灰度通道

如果是灰度图，直接归一化到 [0,1]。
如果是 RGB 伪彩图，建议这样做：

转灰度得到 Y

所有检测与修补都在 Y 上完成

得到校正量 delta = Y_clean - Y

把 delta 等量加回 RGB 三个通道，再裁剪到 [0,255]

这样比“重新映射 colormap”更稳。

最后得到若干 groove tracks。

Step G：生成最终掩膜

沿深度插值出每一行的中心 xc(y) 和宽度 w(y)

掩膜宽度取 w(y) + 2*dilate_x

推荐：

dilate_x = 1~2 px

dilate_y = 0~1 px

然后做一次很轻的形态学 closing，把小缝补上。

Step H：局部重建，而不是全图去条纹

这里是默认修补模块。
我建议 Codex 先实现 两段式修补：

第一段：逐行方位向插值（主修补）

对每一行、每一个 masked segment [a,b]：

在左侧取 k 个上下文点

在右侧取 k 个上下文点

用这些点对该行做 PCHIP / 三次样条 / 加权线性拟合

在 [a,b] 内求值得到 Y_fill

推荐：

k = max(6, 2 * mask_width)

为什么我更推荐逐行插值作为主修补：
因为 groove 是“窄的竖带”，而地质条带、层理、正弦事件在横跨一个很窄的 gap 时通常局部是平滑可延续的。对这类 narrow gap，逐行横向补值往往比整图方向滤波更能保住结构。

第二段：小半径融合（收边）

对第一段修补后的结果，再在 mask 区域做一个 小半径 Telea inpaint 或 Navier-Stokes inpaint，只用于边缘过渡和平滑接缝，不要大半径泛化。OpenCV 官方文档把 inpainting 定义为从邻域边界重建被选区域，也明确适合去除划痕、坏痕迹这类局部缺陷。

推荐：

inpaint_radius = 2 or 3

为什么是“两段式”

单独用 row interpolation：结构延续好，但边缘可能硬

单独用 Telea：窄带可行，但有时会偏向一侧拉纹理

两段结合通常更自然

def clean_grooves(image, cfg):
    img = load_image(image)
    roi = auto_crop(img) if cfg.roi is None else cfg.roi
    img = crop(img, roi)

    img_wrap = circular_pad_x(img, pad=cfg.pad_x)

    Y = to_working_gray(img_wrap)  # float32, [0,1]

    # Step 1: x-direction reference and residual
    Y_ref = median_filter_x(Y, ksize=cfg.k_ref)
    R = Y - Y_ref

    # Step 2: windowed candidate detection
    candidates = []
    for y0, y1 in sliding_windows(height=Y.shape[0],
                                  win=cfg.win_h,
                                  stride=cfg.stride):
        p = np.median(R[y0:y1, :], axis=0)
        b = median_filter_1d(p, ksize=cfg.k_bg)

        if cfg.polarity == "dark":
            q = b - p
        elif cfg.polarity == "bright":
            q = p - b
        else:
            q_dark = b - p
            q_bright = p - b
            q = choose_stronger(q_dark, q_bright)

        z = robust_zscore(q)

        bands = find_contiguous_runs(z > cfg.tau_sigma)
        bands = [band for band in bands if cfg.w_min <= band.width <= cfg.w_max]

        for band in bands:
            a, bnd = band.start, band.end
            ry = np.mean(R[y0:y1, a:bnd], axis=1)
            score = groove_persistence_score(ry, polarity=cfg.polarity)
            if score.persistence >= cfg.persist_min and score.amplitude >= score.amp_min:
                candidates.append(make_candidate(y0, y1, a, bnd, score))

    # Step 3: track linking
    tracks = link_candidates_into_tracks(
        candidates,
        max_drift=cfg.max_drift_per_window,
        min_iou=0.3
    )
    tracks = [t for t in tracks if t.span_frac >= cfg.min_span_frac]

    # Step 4: build mask
    mask = build_mask_from_tracks(
        shape=Y.shape,
        tracks=tracks,
        dilate_x=cfg.dilate_x,
        dilate_y=cfg.dilate_y
    )

    # Step 5: repair
    Y_prefill = rowwise_pchip_fill(Y, mask, context=cfg.interp_context, wrap_x=True)
    Y_clean = small_radius_blend(Y_prefill, mask, method=cfg.blend_method,
                                 radius=cfg.inpaint_radius)

    # Step 6: restore RGB or grayscale
    out = apply_gray_delta_back_to_image(img_wrap, Y, Y_clean)

    # Step 7: crop away wrap padding and save debug outputs
    out = unpad_x(out, cfg.pad_x)
    mask = unpad_x(mask, cfg.pad_x)
    return out, mask, tracks

2D FFT

8. 必须写进项目里的保护机制

让 Codex 一定实现这些，避免误删真实地质：

宽度过滤
宽于 w_max 的带状异常不处理。

最小跨度过滤
只存在很短深度段的竖带，默认不自动修补，只标记为 low-confidence。

未掩膜区最小改动原则
程序应保证未掩膜区域不被改动，或者只允许极小数值差。

review mode
支持先导出 overlay.png 给人审，再执行 clean。

periodic x boundary
所有操作都支持 x wrap-around。

10. 我建议你直接喂给 Codex 的任务提示
Build a Python 3.11 project named borehole_groove_cleaner.

Goal:
Remove stabilizer-grooving artifacts from unwrapped borehole images.
The target artifact is a narrow, vertically persistent band (dark or bright) along depth.
This is NOT decentralization correction and must NOT flatten broad cosine-like shading.

Implement:
1) CLI:
   python -m borehole_groove_cleaner input.png --out out_dir --mode clean
   Optional args: --roi, --polarity dark|bright|auto, --detect-only, --batch

2) Pipeline:
   - load image
   - optional auto-crop borehole panel
   - circular x-padding (periodic azimuth)
   - convert to working grayscale
   - compute row-wise x-median reference and residual
   - sliding-window groove detection using robust column anomaly score
   - reject candidates wider than w_max
   - link candidates across depth windows into tracks
   - build final mask
   - repair masked grooves using row-wise PCHIP interpolation
   - blend with small-radius Telea inpainting
   - apply grayscale correction back to RGB
   - save clean image, mask, overlay, diff, tracks.json, debug plots

3) Config:
   Put all thresholds in a dataclass + YAML support.

4) Unit tests:
   - synthetic groove generator
   - mask detection tests
   - periodic boundary tests
   - repair tests

5) Quality constraints:
   - do not change unmasked pixels except negligible numerical differences
   - reject broad bands as non-groove
   - support wrap-around grooves crossing left/right boundary

6) Nice-to-have optional backends:
   - Fourier/wavelet-Fourier cleanup backend
   - variational stripe decomposition backend

Use:
numpy, scipy, opencv-python, scikit-image (optional), matplotlib, pyyaml
