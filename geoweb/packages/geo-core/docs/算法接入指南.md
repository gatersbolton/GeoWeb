# 算法接入指南（框架版）

## 1. 必须实现的文件
- `algorithm.py`：实现统一接口（`validate_input`、`run`、`get_default_config`）
- `config_schema.py`：Pydantic 参数模型（`safe/advanced/experimental`）
- `capability.json`：算法能力声明
- `tests/`：至少 3 个单元测试
- `README.md`：模块说明

## 2. 必须注册到 Registry
在`algorithms/bootstrap.py`中注册新算法，禁止在 API 路由中硬编码调用。

## 3. 占位实现约定
当前框架阶段允许“输入即输出”占位，后续替换`run()`算法主体即可。
