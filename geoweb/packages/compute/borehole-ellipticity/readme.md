# packages/compute/borehole-ellipticity

Purpose
- Borehole ellipticity computation and visualization.

Contents
- borehole_ellipticity.py: main computation entry.
- functions.py: algorithm utilities.
- vis_wrapper.py: plotting helpers used by the service.
- data/: demo CSV inputs and sample outputs.
- vis/: visualization scripts.
- images/: figures.

Notes
- Contains legacy virtualenv folders (ellipticity, ellipticity_env_310); not used by apps.
